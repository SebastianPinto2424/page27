Practica de Git, GitHub y GitHub Pages

Pagina creada para practicar repositorios, ramas, commits, pull request y despliegue con GitHub Pages.

Objetivo de la practica

En este repositorio se practica el uso de Git y GitHub mediante un archivo en C con funciones matematicas simples y una pagina web estatica publicada con GitHub Pages.

Funciones en C incluidas

  • Funcion de saludo
  • Suma de dos numeros
  • Resta de dos numeros
  • Multiplicacion de dos numeros
  • Division de dos numeros
  • Calculo del cuadrado de un numero
  • Calculo del promedio de tres notas

Comandos practicados

git status

git add .

git commit -m "Agrega funciones y pagina web"

git push

GitHub Pages

Esta pagina puede ser publicada desde la configuracion del repositorio en:

Settings > Pages > Deploy from a branch > main > /root
